# e-plantShopping: Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux Toolkit shopping application that lets users browse houseplants by category, add plants to a cart, adjust quantities, remove items, and view dynamic totals.

## Required features
- Landing page with `Welcome to Paradise Nursery` and a functional `Get Started` button
- About Us company information
- 18 plants across 3 categories
- Product images, names, descriptions, and prices
- Dynamic cart icon quantity
- Redux reducers: `addItem`, `removeItem`, and `updateQuantity`
- Cart quantity controls, item totals, overall total, delete, checkout message, and continue shopping

## Run locally
```bash
npm install
npm run dev
```
